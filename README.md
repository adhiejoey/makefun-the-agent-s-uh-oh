One word an agent blurts when it is completely lost: **recalculating** — the
sat-nav voice of a machine that has missed its turn, has no idea where it is,
and is stalling for time by announcing it is doing something about it.

## How it works

`main.ts` writes the single word `recalculating` to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), after checking
it is 1–99 non-whitespace characters.
